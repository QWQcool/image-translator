# 成本估算与容量规划（v3：登录墙 · 原图直出 · 国内备案）

> **最新前提（2026-09-01 确认）**：
> - **全站登录墙**（未注册/未登录无法访问任何内容，无公开访客流量）
> - 注册用户约 100 人（互相认识的熟人圈子），**同时在线 10~20 人**
> - **原图直出**（存储不压缩，网格浏览用缩略图，双击/编辑器看原图）
> - 图片处理完存储、过一段时间即删除，**不长期堆积**（同时存量 ~10~30GB）
> - **国内部署 + ICP 备案**（非牟利 + 轻微擦边 + 邀请制私密圈子 + 发现即删，风险可控）
> - 推特 API 由网站统一指定一批账号采集（每 3 天增量）
> - 可选：空闲时在同机/另机开《我的世界》服务器（见第九节）

> 价格取自腾讯云官方价格总览（2026-09 检索）。

## 二、流量与带宽（10~20 人在线，无访客）

### 2.1 月流量

```
浏览：20 活跃人 × 每人每天 ~100MB（缩略图浏览 + 双击拉原图）× 30 天 ≈ 60GB/月
上传：每天 50~100 张 × 2MB ≈ 5GB/月
合计 ≈ 65GB/月
```

### 2.2 带宽是唯一关注点

| 场景 | 需求 |
| --- | --- |
| 浏览缩略图 | 很小，3Mbps 都够 |
| **多人同时拉原图（原图直出）** | 同时 3~5 人 × 1~3MB ≈ **24~64Mbps 瞬时** |
| 多人同时上传（sharp 处理） | 入带宽 + CPU 压力 |

| 套餐 | 带宽 | 够不够 |
| --- | --- | --- |
| 轻量 2核2G | 3~4Mbps 固定 | ⚠️ 3 人同时拉原图就卡，上传 2MB 图 3~5 秒 |
| **锐驰型 2核8G** | **200Mbps 无限流量** | ✅ 20 人随便并发，65GB/月是零头 |

**结论：流量费不用省（都在套餐内/无限），真正的分水岭是"带宽峰值"。原图直出 + 多人协作 → 选锐驰型最省心。**

## 六、域名 / 备案 / 登录（新增，重点）

### 6.1 为什么域名必买：登录依赖 HTTPS

生产模式下登录 Cookie 带 **`Secure`** 属性，浏览器只在 HTTPS 连接下接收/回传该 Cookie。
**纯 HTTP（IP:端口）下：登录提交成功但会话建立不起来**——表现为"登录了跟没登录一样"，
注册能成功（不依赖 Cookie）但注册后自动登录同样失败。

### 6.2 三方案对比

| 方案 | 域名 | 备案 | HTTPS/登录 | 月度成本 | 首付 | 评价 |

## 十、关键提醒

1. **媒体接口千万别放开**（登录墙下保持 401 + `Cache-Control: private`），否则图片 URL 裸奔。
2. **HTTPS 是登录的前提**：`Secure` Cookie 在纯 HTTP 下不生效，必须域名+证书（正式）或改代码/自签（临时）。
3. **原图直出后磁盘涨得快**：存量超系统盘 60% 前升级套餐或加盘（当前删图模式存量 10~30GB，无忧）。
4. **备案最先启动**（10~20 天），域名实名（1~3 天）与服务器购买（3 个月起）同步进行，审核期正好做开发。
5. 内容合规红线：**止步轻微擦边，杜绝露骨内容**；配合「违规内容下架机制」（见待做功能清单 P3-18）。
