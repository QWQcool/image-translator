> **最新前提**：国内部署 · **全部共享空间（无私人空间）** · 注册用户约 100 多人 ·
> **日均 1000 名未注册访客直接浏览** · 素材来源为「推特 API 采集 + 用户手动上传到共享空间」
>
> 价格取自腾讯云官方文档（2026-06 版）与 Cloudflare R2 官方定价页（2026-08 版）。
> 汇率按 **1 USD ≈ 7.2 CNY**。

这一条决定了每月是 ¥90 还是 ¥54,000 —— 相差 600 倍。

## 二、流量与带宽（1000 未注册访客/天）

### 2.1 单次访问的数据量

| 内容 | 体积 |
| --- | --- |
| 页面 HTML + JS/CSS（gzip 后，后续访问走缓存） | ≈ 110 KB |
| 缩略图（520 宽 WebP） | **35 KB / 张** |
| 原图（最长边 1800 的 WebP） | **220 KB / 张** |

按单个访客浏览 2~3 个空间页（约 50 张缩略图）+ 打开 3 张大图估算：

```
50 × 35 KB + 3 × 220 KB + 110 KB  ≈  2.5 MB / 访客
```

### 2.2 月流量

```
1000 访客/天 × 30 天 × 2.5 MB  ≈  75 GB/月
```

加上注册用户的上传与编辑活动（约 300 MB/月），**总计 ≈ 75 GB/月**。

CDN 费用（中国大陆 ≈ ¥0.2/GB）：**≈ ¥15/月**。流量本身很便宜。

### 2.3 带宽才是真正的瓶颈

访客浏览图片是**突发式**的 —— 滚动一下就一次性拉 20 张缩略图（700 KB）。

假设峰值 30 人同时在线滚动浏览：

```
30 人 × 700 KB / 2 秒  ≈  10.5 MB/s  ≈  84 Mbps 瞬时峰值
```

**这个量级普通服务器带宽扛不住**（入门型只有 10~14 Mbps）。必须二选一：

| 方案 | 说明 |
| --- | --- |
| **上 CDN（推荐）** | 图片全部走 CDN 边缘节点，服务器只出 API 和 HTML（很小）。延迟也更低 |
| 用锐驰型 | 200Mbps 峰值 + 无限流量，能硬扛，但跨省延迟不如 CDN |

**推荐 CDN**：费用仅 ¥15/月，还能顺带把国内跨省访问延迟压下来。

## 四、服务器选型

负载画像：

- 日均 1000 访客 ≈ 0.7 次请求/秒，峰值约 10~20 req/s
- 图片几乎全走 CDN，服务器只处理 API 与页面渲染
- sharp 处理上传是唯一的 CPU/内存密集操作，但上传量小且已做并发限流

| 套餐 | 规格 | 月租 | 建议 |
| --- | --- | --- | --- |
| 锐驰型 2核8G | 200Mbps 峰值 / **无限流量** | **¥105**（年付 ¥89） | ✅ 够用，推荐起步 |
| 锐驰型 4核8G | 200Mbps 峰值 / 无限流量 | ¥230（年付 ¥196） | 流量翻倍后升级 |
| 通用型 4核8G | 12Mbps / 2000GB | ¥230 | ❌ 带宽不够，必须配 CDN |

**推荐 2核8G 起步（¥105/月，年付 ¥89）**，不够再升 —— 腾讯云支持在线升配，不用迁移。

> 为什么内存要 8G 而不是 4G：sharp 解码大图很吃内存，
> 多人同时上传 20MB 图片时 4G 有 OOM 风险（当前已限制同时处理 2 张）。

## 五、推特 API：唯一的大变量

读取单价 **$0.005/条**，24 小时内同一条推文去重不重复计费。

### 情形 A：网站统一采集一批账号（推荐）

| 项目 | 计算 | 成本 |
| --- | --- | --- |
| 首抓 50 个账号 × 100 条 | 5000 条 × $0.005 | $25（一次性） |
| 增量（每天） | 50 × 5 条 × 30 天 × $0.005 | **$37.5/月 ≈ ¥270** |
| 增量（每 3 天） | 7500 / 3 条 × $0.005 | **$12.5/月 ≈ ¥90** |

**省钱的三个旋钮**：

1. **降频率**：每天 → 每 3 天，成本直接降到 1/3。对「翻译素材站」来说，
   内容晚 3 天出现用户几乎无感
2. **精选账号**：50 个高质量账号比 200 个账号的效果未必差，成本却是 1/4
3. **限制首抓深度**：用 `start_time` 只抓近 30 天，而不是回溯全部

### 情形 B：让 100 多个用户各自抓自己的关注者

```
100 人 × 300 关注者 × 50 条 = 150 万条 × $0.005 = $7,500/月 ≈ ¥54,000
```

❌ **完全不可行**。即使把深度压到极限（20 条）也要 $500/月。

### 情形 C：BYOK（用户自带 API Key）

用户填自己的 Bearer Token，服务器代抓他自己的关注者，费用记在他自己的 X 开发者账号上。

**你承担：¥0**，而且每个用户拿到的还是自己真正关心的内容。

### 情形 D：完全不接 API，纯手动上传（最省钱）

**API 费用：¥0**，只剩基础设施 ¥110/月。

手动上传的代价是**用户时间**，不是钱：

| 方式 | 单张耗时 |
| --- | --- |
| 粘贴图片直链（`pbs.twimg.com`） | ≈ 5 秒，几乎无感 |
| `Ctrl+V` 粘贴剪贴板图片 | ≈ 10 秒 |
| 下载文件再上传 | ≈ 30 秒 |

而且手动上传有个**被低估的优势：内容更精准**。
用户只会上传自己真正想翻译的图，而 API 采集会抓来大量无关内容 —— 既占存储，又稀释内容价值。

**建议：先纯手动跑起来（¥110/月），观察内容供给速度。供不上了再上 API。**

> 三种路径的取舍：
> - **纯手动**：¥110/月，冷启动慢，内容质量高
> - **手动 + 统一采集**：¥200/月，有保底内容，但可能混入无关图
> - **BYOK**：¥110/月，内容个性化，但需要用户愿意去申请 API Key

## 七、一个必须先解决的功能缺口：未注册访客

**当前代码所有接口都要求登录**，未登录访问会返回 401/404。
要支持「1000 未注册访客直接浏览」，需要改造：

| 改造点 | 说明 |
| --- | --- |
| 空间列表 / 详情接口 | 对未登录访客开放共享空间的只读访问 |
| **图片媒体接口** | 目前强制登录，访客看不到任何图 —— 这是致命的 |
| 前端 | 未登录时隐藏编辑入口，显示登录/注册引导 |
| 导出 | 需决策：访客能否导出标注 |

### 媒体接口的设计取舍

既然「全部是共享空间」，图片本身也都是公开的。
那么媒体接口可以直接**放开鉴权**，好处是：

- CDN 可以直接缓存图片，性能最好、成本最低
- 少一次数据库查询，降低服务器压力

代价是将来若出现私有内容，需要额外加签名 URL 机制。

**建议：现阶段直接放开读权限**（反正全是共享内容），代码里保留扩展点。

### 关键提醒

1. **媒体接口的 `Cache-Control` 必须改成 `public`**，否则 CDN 不缓存，
   1000 访客/天的突发加载会打满服务器带宽（实测瞬时峰值 ~84 Mbps）
2. **图片全部公开**意味着任何人拿到 URL 都能访问 —— 这是当前决策的正确结果，
   但将来若需要私有内容，必须再加签名 URL 机制
3. 上线前**最先启动 ICP 备案**（10~20 天），否则服务器买好了也用不了

具体改造步骤见 `docs/待做功能清单.md`。

## 九、ICP 备案的真实成本

### 直接费用：**¥0**

腾讯云、阿里云代办备案都不收费（工信部本身也不收）。

### 但有间接成本，别漏算

| 项目 | 说明 | 金额 |
| --- | --- | --- |
| **服务器需买 3 个月起** | 备案的硬性要求，月付的话要一次买 3 个月 | 首次预付 **¥315**（¥105×3），或年付 ¥1,071 |
| **时间成本** | 审核 10~20 个工作日，省份不同差异大 | 提前启动，别卡上线时间 |
| **备案期间域名无法访问** | 审核未通过前，域名不能解析到大陆服务器 | 这段时间只能 IP 访问或暂不开放 |
| 域名实名认证 | 免费，但需提前完成（一般要求实名满 3 天才能提交备案） | ¥0 |
| 人脸核验 | 现在主流是 APP 刷脸，免费（早期要幕布照片，也是免费邮寄） | ¥0 |
| 加急 / 备案管家 | 部分服务商的增值服务，非必需 | ¥0（不买即可） |

### 结论

**备案本身不花钱，但会占用 10~20 天，并要求服务器至少买 3 个月。**

所以要算的是**首次启动的一次性支出**：

```
服务器 3 个月 ¥315  +  域名 ¥60/年  =  ≈ ¥375（首次支出）
```

之后按月的成本仍是上表的 ¥110 ~ ¥380。

> 实操建议：**先买服务器（3个月起）和域名，立刻提交备案，备案审核期间正好用来做功能开发**。
> 这样备案下来时功能也差不多了，不浪费时间。
