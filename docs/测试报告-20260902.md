### ⚠️ 设计层面提示（非阻塞，但建议排期）

1. **注册限流是进程内内存 Map**，且 `clientIp()` 取不到 `X-Forwarded-For` 时统一记为 `"unknown"`：
   - 本次测试中一次「第 4 次注册」意外返回 200，怀疑是 dev 下模块重载导致 Map 被清空。多进程部署（cluster / PM2 / 多副本）时 3 次/小时会变成「每进程 3 次」。
   - 直连（无反代）时所有用户共用一个桶，第 4 个人就注册不了。
   - 建议：换 Redis / DB 计数，并在无 XFF 时回退到 socket 远端地址。
2. **登录失败无次数限制**：错误密码只有 401，没有锁定/退避，可暴力枚举。

### 🐛 Bug：`sidecar/stub.mjs` 起不来（阻塞清单里「健康检查通过」这一步）

```
ReferenceError: require is not defined in ES module scope
    at file:///.../sidecar/stub.mjs:6:14
```

`.mjs` 在 Node 下按 ESM 解析，但文件里用的是 CommonJS 的 `require('node:http')`，`node sidecar/stub.mjs` 一启动就崩。本次测试是临时写了一份 ESM 版 stub 才跑通「health 通过 → 502」这条用例。

修法（任选）：把 `require` 改成 `import http from 'node:http'`，或把文件改名为 `stub.cjs`。
